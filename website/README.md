# BendMe website

Public maker landing page at https://winsonbaring.github.io/bendme/ with a real GPU-rendered interactive preview, free desktop download, Winson Baring's public profile, installation guidance, and privacy information.

See [SETUP.md](SETUP.md) for commands, [PROJECT.md](PROJECT.md) for architecture, and [ASSETS.md](ASSETS.md) for provenance. No analytics, forms, cookies, or remote embeds are included.

The primary download points directly to the versioned DMG asset on GitHub Releases; binaries are not stored in GitHub Pages.

The current direct download includes a Developer ID signed app with a validated Apple notarization ticket.

The current v0.1.3 download includes a Dock icon and settings-window restoration, alongside menu-bar controls.

The first-start FAQ directs users to the interactive Setup guide, with a floating permission companion and live checks in the app.

Version 0.1.3 includes a prominent missing-app branch in the native guide; the FAQ points to it when no permission row appears.
