# Security

Do not post secrets, private desktop images, or exploit details that expose another person in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/WinsonBaring/bendme/security/advisories/new) when enabled. If that interface is unavailable, open an issue asking the maintainer for a private reporting channel without including sensitive details.

BendMe intentionally processes screen frames only in memory. Website reports should include the affected public URL and reproduction steps without account credentials. The development preview is not yet notarized; do not disable macOS security protections to run it.
